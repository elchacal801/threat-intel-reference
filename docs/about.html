About

What is this?

An open-source, daily-updated reference database of known malware, PUPs (Potentially Unwanted Programs), and PUAs (Potentially Unwanted Applications). Data is aggregated from multiple free threat intelligence sources into normalized, downloadable CSV and JSON files.

Use it as a reference for detection coverage analysis, threat research, or any workflow that needs a comprehensive list of known threats.

Download Data

All data files are in the data/ directory of this repository:

  • data/raw/ — Raw per-source CSVs, as-ingested
  • data/normalized/malware_samples.csv — All malware samples
  • data/normalized/pup_pua_samples.csv — PUP/PUA/adware/riskware samples
  • data/normalized/malware_families.csv — Canonical family list with aliases
  • data/normalized/iocs.csv — IOCs from ThreatFox
  • data/normalized/techniques.csv — MITRE ATT&CK technique mappings

Fork & Use Your Own Keys

  1. Fork this repository
  2. Register for free API keys at auth.abuse.ch
  3. Add your keys as GitHub Secrets: MALWAREBAZAAR_API_KEY, THREATFOX_API_KEY, YARAIFY_API_KEY
  4. Enable GitHub Actions on your fork
  5. Run the Manual Pipeline workflow to verify, or wait for the daily 6 AM UTC cron

Contributing

Contributions welcome! To add a new data source:

  1. Create a new collector in collectors/ extending BaseCollector
  2. Add tests in tests/
  3. Register it in run_pipeline.py
  4. Update the normalizer if the source provides sample-level data
  5. Open a PR
